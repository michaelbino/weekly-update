Each week

  1. Newsletter › Start next issue copies this Doc and updates the date.
  2. Edit the copy. Rename it to change the email subject.
  3. Newsletter › Publish web version once per issue. This puts the email-look page behind “View in browser”; each preview you send refreshes it.
  4. Newsletter › Send preview to me, check it on your phone, fix, resend.

How the Doc becomes the email

Title style
Newsletter name in the coloured header band.
Subtitle style
The date line under it.
Image above the Title
Replaces the text header with your own banner (1400×560 works well).
Heading 1
Starts a section. A divider line is drawn above it automatically.
Heading 2 / 3
Smaller headings inside a section.
Normal text
Bold, italic, underline, colour, links, alignment and bullet/numbered lists carry over. Blank lines become spacing.
Images
Full-width images stay full width; smaller ones keep their size. Set alt text with right-click › Alt text.
Insert › Horizontal line
An extra divider, e.g. between two image-only sections.
A line that is only a Drive file link or file chip
Becomes a download card (PDF flyers, forms). Share the file “Anyone with the link”.
Tables
Rendered as simple bordered tables.
Translations
Once the web version is published, each language in Settings gets a machine-translated page, linked from the 🌐 row at the top of the email. Text inside images (flyers) is not translated, so put key dates, times and costs in the Doc text too.
